Web Development Basics

Every website you visit is built from three core technologies working together.

Lesson 1: Understanding HTML

Level: Beginner • Reading time: 5 minutes

HTML (HyperText Markup Language) gives a webpage its structure. It uses elements written with tags to describe headings, paragraphs, links, images, lists, and more. Semantic elements such as <header>, <nav>, <main>, and <footer> tell browsers and screen readers what each part of the page means.

Lesson 2: The Three Pillars of the Web

Level: Beginner • Reading time: 4 minutes

How HTML, CSS, and JavaScript differ
Technology Role Analogy
HTML Structure and content The skeleton of a house
CSS Presentation and layout Paint, furniture, and decoration
JavaScript Behavior and interactivity Electricity and plumbing

Python Programming

Python is a readable, versatile language used in web development, automation, data science, and more.

Lesson 3: Variables and Control Flow

Level: Beginner • Reading time: 6 minutes

A variable stores a value so you can use it later. Control flow statements such as if, for, and while let your program make decisions and repeat actions.

Try it yourself:

  1. Change score to a value below 50 and predict the output.
  2. Change the range so the loop runs five times.
  3. Add an elif branch that prints a message for scores of 90 or higher.

Lesson 4: Project Idea — A Number Guessing Game

Level: Beginner • Build time: 45 minutes

Practice what you have learned by building a small game. Your program should:

  • Pick a random number between 1 and 100.
  • Ask the player for guesses and respond with “higher” or “lower”.
  • Count the number of attempts and display it at the end.
  • Offer to play again.

Data Structures & Algorithms

Choosing the right way to organize data makes programs faster and easier to reason about.

Lesson 5: Common Data Structures at a Glance

Level: Intermediate • Reading time: 8 minutes

Array / List
An ordered collection with fast access by position (index).
Stack
Last in, first out (LIFO). Think of a pile of plates; used for undo features and function calls.
Queue
First in, first out (FIFO). Think of a line at a shop; used in task scheduling.
Hash Table / Dictionary
Stores key–value pairs for very fast lookups.
Tree
A hierarchy of connected nodes, such as a file system or a family tree.

Lesson 6: Why Algorithm Speed Matters

Level: Intermediate • Reading time: 5 minutes

Big-O notation describes how an algorithm’s running time grows as the input grows. Here is a quick comparison of common growth rates:
